# Project page assets

The figures and replay frames are taken from the authors' supplied manuscript. The interactive example presents archived paper outputs and does not run model inference. ChronoReplay's frames retain the original embedded JPEG bytes; ViSS uses the paper's timestamped frames.

Manrope and Space Grotesk are self-hosted from the Google Fonts distribution, under the SIL Open Font License. Their license notices are in `fonts/`. These font licenses apply to the fonts, not to paper figures or third-party video content.
